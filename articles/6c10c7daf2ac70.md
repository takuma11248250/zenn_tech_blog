## de-questとは

[de-quest](https://de-quest.com/) は、データエンジニアに必要なスキルを体系立てて学べる個人開発の学習教材アプリです。技術的なスキルだけでなく、実務で評価される行動特性まで含めて、次の5つのスキルルートに分けて構成しています。

| ルート | 学べる内容 |
| --- | --- |
| 主体性・自立性 | 指示待ちにならず、自分で課題を見つけて動く力 |
| 問題解決力 | トラブルや制約に対して、筋道を立てて解決する力 |
| チーム貢献度 | チームの成果を最大化するための立ち回り |
| コミュニケーション能力 | 事業部やチームメンバーとの円滑な連携 |
| 技術力 | Linux/Git/SQL/GCP/dbtなど、実務で使う技術そのもの |

**各ルートは20ステージ+総集編1ステージの、合計21ステージ構成**です。1ステージずつ順番に進めていくことで、断片的な知識ではなく、実務のシチュエーションに沿った形でスキルが積み上がっていくように設計しています。

## 4択の実践問題形式と、ハンズオン形式の使い分け

de-questのステージは、大きく2種類の形式で構成しています。

**主体性・自立性、問題解決力、チーム貢献度、コミュニケーション能力の4ルート**は、実際のデータエンジニア業務でありがちなシチュエーションを題材にした4択の実践問題形式です。各ステージに10問ずつ用意しており、単なる知識確認ではなく、「一見良さそうに見えるが実務では避けるべき選択肢」を誤答に混ぜることで、**実務での判断力そのものを試す設計**にしています。

一方で**技術力ルートだけは、問題集ではなくハンズオン形式**を採用しています。技術は座学で読むだけでは身につかず、実際に手を動かして初めて定着すると考えたためです。

## 技術力ルート——全21ステージ、実際に手を動かして作る教材

技術力ルートは、Linuxの基礎からアーキテクチャ設計まで、データエンジニアに必要な技術要素を一気通貫でハンズオン化しました。

- Linux/CLIの基礎〜応用(ログ監視・自動アーカイブスクリプト)
- Git/GitHubの基礎〜応用(feature branch運用・コンフリクト解消・rebase)
- Pythonの基礎(公開APIから取得したデータをCSV/JSON保存する簡易ETL)
- SQLの基礎(ECサイト風ミニDBでJOIN・集計・サブクエリ)
- ネットワークの基礎(DNS・CIDR計算・HTTP/HTTPS)
- GCPの基礎〜応用、Terraform、データセキュリティ、コンテナ、データ監視、BigQuery、オーケストレーション、アーキテクチャ設計、CI/CD、dbt、データ品質、モデリングアーキテクチャ
- 新技術の調査・評価・提案、コード設計とレビューの実践
- 総集編(学習ログ集計基盤という1つのミニプロジェクトに、20ステージの要素を統合)

すべてのステージで、**「作って終わり」ではなく必ず動作確認の手順を含める**ことにこだわりました。コマンドを打って終わりではなく、期待する出力や終了コードまで確認して初めてステージクリアになる、という構成です。

作問の過程でも、可能な限り自分の手元環境で実際に手順を実機検証してから公開しています。Docker Composeでのコンテナ間通信の確認、dbt-duckdbでのローカルパイプライン構築、Airbyteの実デプロイと同期実行など、**教材の中の手順は極力「実際に動くことを確認済み」の状態で提供する**ようにしています(GCPの本番リソース作成が絡む一部の手順は、コストや権限の都合でコマンドのドラフト提示に留めています)。

## de-questを支える技術

de-questはNext.js + Supabaseで構築しています。個人開発ということもあり、インフラをできるだけシンプルに保ちつつ、学習コンテンツ自体の質に開発の比重を置きました。

## まとめ

- データエンジニアに必要なスキルを5ルート(主体性・自立性、問題解決力、チーム貢献度、コミュニケーション能力、技術力)に分けて学べる個人開発アプリ[de-quest](https://de-quest.com/)をリリースしました
- 4ルートは実務シチュエーション型の4択問題(各21ステージ×10問)、**技術力ルートだけは問題集ではなく実際に手を動かすハンズオン形式**にしています
- 技術力ルートは全21ステージで、Linux/Gitの基礎からGCP・dbt・アーキテクチャ設計まで一気通貫でカバーし、可能な範囲で手順を実機検証したうえで公開しています
